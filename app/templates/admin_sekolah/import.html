Panduan Import Data

  • Murid: Import menggunakan NISN sebagai ID unik. NISN harus 8-12 digit angka.
  • Guru: Import menggunakan Nomor Pegawai sebagai ID unik per sekolah.
  • Email: Bersifat read-only setelah dibuat. Untuk keamanan, email tidak bisa diubah dari dashboard. Hubungi Super Admin jika perlu ganti email.
  • Password: Password default akan digenerate otomatis (12 karakter). User bisa ganti password setelah login.
  • Sekolah: Semua data terikat dengan NPSN sekolah Anda. Data dari sekolah lain tidak akan tercampur.

Upload File Excel

File Excel dengan 3 sheet: Murid, Guru, dan Mata Pelajaran.

Format: .xlsx, .xls

Sheet: Murid

NISN — 8-12 digit, unik

Nama — Nama lengkap

Kelas — Contoh: VII-A

Level — Opsional

Email — Opsional, jika kosong akan digenerate

Sheet: Guru

Nomor Pegawai — Unik per sekolah

Nama — Nama lengkap

Mapel — Nama mata pelajaran

Email — Opsional, jika kosong akan digenerate

No HP — Opsional

Sheet: Mapel

Nama Mata Pelajaran — Contoh: Matematika

Kode — Opsional, contoh: MTK
