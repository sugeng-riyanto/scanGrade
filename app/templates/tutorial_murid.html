Cara Mengerjakan Ujian

Panduan lengkap — dari login, menjawab soal, hingga melihat nilai.

1

Login & Pilih Ujian

Masuk dengan akun dari sekolah. Di dashboard, klik ujian yang tersedia. Kamu hanya akan melihat ujian untuk kelasmu.

Jawaban tersimpan otomatis — aman meskipun internet terputus.

2

Jenis Soal & Cara Jawab

Ada 3 tipe soal:

MCQ

Klik A, B, C, D, atau E. Jawaban terpilih menyala oranye.

Esai Teks

Tulis jawaban paragraf di kotak teks yang tersedia. Panjang bebas.

Esai Canvas

Gambar & tulis langsung di atas halaman PDF dengan berbagai alat.

3

Tools Menggambar & Mengukur

Untuk soal Esai Canvas, gunakan alat-alat ini:

Pena

Garis

Hapus

Ruler 30cm

Busur 180°

Siku 45°

Jangka

Teks

Kalkulator*

Undo

*Kalkulator hanya jika diaktifkan guru.

4

Anti-Cheat

Jangan berpindah tab selama ujian. Sistem mendeteksi dan memberi sanksi bertahap:

{% set base = 5 %} {% set maxv = 5 %}
1xPeringatan (0 poin)
2x-{{ base }} poin
3x-{{ base * 2 }} poin
4x+-{{ base * 3 }} poin per pelanggaran

Maksimal {{ maxv }} pelanggaran → ujian otomatis dikumpulkan.

5

Kumpulkan & Lihat Nilai

Klik "Kumpulkan" setelah selesai. Jika guru mengatur publikasi otomatis, nilai langsung muncul. Jika manual, tunggu guru mengoreksi. Download PDF hasil ujianmu kapan saja.
