Koreksi Essay Otomatis Pakai AI

ScanGrade bisa koreksi jawaban esai siswa secara otomatis. Kamu tinggal pilih provider AI di bawah, dapatkan API Key gratis, dan selesai.

💡 Ini cara kerjanya:

  • 1. Pilih provider AI (rekomendasi: Gemini — gratis)
  • 2. Dapatkan API Key (seperti "kunci rumah" untuk akses AI)
  • 3. Tempel key-nya di sini → AI siap bantu koreksi

Pilih Provider AI:

Dapatkan API Key

Gemini — Gratis, tanpa kartu kredit

Cukup punya akun Google (Gmail). Ikuti 5 langkah di bawah.

Total waktu: 5 menit. Yang kamu butuhkan cuma akun Google.

1

Buat API Key

Klik tombol di bawah, login dengan Google, lalu klik "Create API Key".

Buka Google AI Studio → Buat API Key
2

Copy Key

Copy key yang muncul (bisa diawali AIzaSy atau AQ.). Key panjang, pastikan tercopy semua tanpa spasi.

3

⚠️ Aktifkan Gemini API (wajib!)

Buka halaman di bawah, pastikan project yang dipilih sama dengan project key kamu, lalu klik ENABLE. Tunggu 2-5 menit.

Buka Google Cloud → Enable Gemini API

Di pojok atas kanan, pastikan project-nya sesuai: My Project (557976847295) atau nama project key kamu.

4

Paste Key di sini

Tempel key yang sudah dicopy ke kolom di bawah.

5

Test Koneksi

Klik tombol Test di bawah. Kalau muncul ✅ berarti siap digunakan.

Groq — Gratis, cepat

Daftar di console.groq.com, dapatkan API Key gratis.

  1. 🔗 Buka console.groq.com/keys
  2. 📝 Daftar akun (bisa pakai Google)
  3. 🔑 Klik "Create API Key", copy key-nya (gsk-...)
  4. 📋 Tempel key di bawah

DeepSeek — Gratis, tanpa kartu kredit

  1. 🔗 Buka platform.deepseek.com
  2. 📝 Daftar akun
  3. 🔑 Buat API Key, copy
  4. 📋 Tempel key di bawah

OpenAI — Berbayar (dapat $5 gratis)

Perlu kartu kredit. Dapat $5 kredit gratis.

  1. 🔗 Buka platform.openai.com/api-keys
  2. 📝 Login/daftar
  3. 🔑 Klik "Create new secret key", copy (sk-...)
  4. 📋 Tempel key di bawah
