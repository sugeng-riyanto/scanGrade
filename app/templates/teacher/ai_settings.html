Apa itu API Key? Seperti kunci untuk menghubungkan ScanGrade ke AI. Dengan kunci ini, AI bisa membantu mengoreksi jawaban esai siswa.

Kamu cukup punya SATU kunci dari provider mana pun di bawah ini.

⭐ Gemini (Paling Mudah)

Gratis, tanpa kartu kredit.

  1. Buka aistudio.google.com/apikey
  2. Klik "Create API Key"
  3. Copy key-nya, paste di form

🤖 OpenAI

Kualitas terbaik. Dapat $5 gratis.

  1. Buka platform.openai.com/api-keys
  2. Login, klik "Create new secret key"
  3. Copy key (sk-...)

🧠 DeepSeek

Termurah, tanpa kartu kredit.

  1. Buka platform.deepseek.com
  2. Daftar, buat API Key
  3. Copy key

⚡ Groq

Gratis 30 req/menit.

  1. Buka console.groq.com/keys
  2. Daftar, buat API Key
  3. Copy key (gsk-...)
