A language switch names its *target* in the target language, so the label is a ternary rather than a `t()` pair — `t()` would render the current language, which is the language the reader already has. #} {% macro lang_button() %} {% endmacro %} {# A message the server built, in whichever language the reader chose. The language is in localStorage, so the server cannot know it at render time — the route supplies an (id, en) pair and this picks a half. Both halves are rendered by Jinja and chosen by Alpine, rather than interpolated into an Alpine expression, because a school name containing an apostrophe would close that JavaScript string early and leave the alert empty. That is data, not copy. `x-cloak` on both spans because the app's default language is English: without it an Indonesian reader would see the English half flash before Alpine hid it, and with it the alert behaves like every `x-text` on the page — empty for the first paint, correct immediately after. Each half carries its own `lang`. Both halves are in the document at once and Alpine only *hides* one, so a screen reader that reads the tree before Alpine runs — or a reader with scripting off, where `x-cloak` is the only thing hiding anything — otherwise announces a message twice, in the same voice, in two languages.
