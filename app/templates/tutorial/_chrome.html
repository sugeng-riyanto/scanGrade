{# The tutorial headers — written once, used by all three role tutorials. `tutorial_guru`, `tutorial_murid` and `tutorial_admin_sekolah` are the pages a school reads *before* it signs up, so they carry the same contract as the landing page and `/capacity`: a language control on the page itself, and a header that survives a 320px phone. They used to write that header three times, and both defects were in each copy: no language button at all — so a visitor arriving from a search engine got English copy with no way to ask for Indonesian, because the toggle lives in base.html's *authenticated* chrome, which these pages never render — and a long "Log in as Teacher" button that ran past the right edge of a 320px screen. The button and the responsive rules live here once, so a fourth tutorial cannot quietly reproduce either one. A partial has no Alpine scope of its own: it is inlined where it is used, so `lang` and `t()` below resolve from the caller's ``. #} {# The language control. The label names the language you would switch *to*, read from the same `lang` the content uses — same convention as the landing page. The aria-label says it in words, because the visible text is a two-letter code: a screen reader announcing "ID" tells the listener nothing about what pressing it does. A language switch names its *target* in the target language, so the label is a ternary rather than a `t()` pair — `t()` would render the language the reader already has. #} {% macro lang_button() %} {% endmacro %} {# The header itself.
