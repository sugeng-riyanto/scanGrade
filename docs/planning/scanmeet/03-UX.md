# 03 — UI/UX dan perangkat

## Alur ujian

Guru/admin melihat kartu ScanMeet di pengaturan ujian: OFF/siap/live/bermasalah,
status lisensi, kuota, durasi, pengawas, ON/OFF, Mulai, Buka, Bagikan dan Akhiri.
Jangan menyembunyikan seluruh kartu ketika feature flag OFF: tampilkan alasan dan
langkah admin yang jelas tanpa mengekspos konfigurasi rahasia. Nama produk ScanMeet,
bukan Uji Video LiveKit untuk pengguna akhir.

Murid membuka ujian yang sama. Ketika OFF tidak ada SDK/media capture yang dimulai.
Ketika ON tampil panel pengawasan, tujuan izin kamera, preview dan tombol Bergabung.
Izin kamera setelah tindakan murid, tanpa navigasi/tab baru. Kontrol mikrofon baru
tersedia setelah izin pengawas; kamera/koneksi bermasalah tidak menambah pelanggaran.
Panel tidak menutupi soal, kanvas jawaban, timer, tombol simpan atau submit. Fullscreen
permission overlay, scrolling, rotation dan interaksi panel tidak boleh menyebabkan
false-positive; jangan mematikan anti-cheat global sebagai solusi.

## Alur meeting

Daftar meeting → buat/jadwalkan → pilih audience → lobby preview/perangkat → mulai/
bergabung → controls peserta, chat, raise hand dan screen share → akhiri → presensi/
ekspor. Pilihan kamera dan mic mengikuti Jumpa; user tetap bisa OFF sebelum masuk.
Simpan preferensi per user/browser dalam namespace ScanMeet, bukan key Bahasa Cerdas.
Tampilkan status izin, gagal, mencoba kembali dan kemampuan yang tidak didukung.

## Matriks layout dan bukti

| Kelompok | Lebar uji CSS px | Orientasi | Browser target |
| --- | --- | --- | --- |
| HP kecil | 320, 360, 390 | Portrait + landscape | Chrome Android, Safari iPhone |
| HP besar | 430 | Keduanya | Chrome Android, Safari |
| Tablet | 768, 820, 1024 | Keduanya | Safari iPadOS, Chrome Android |
| Laptop | 1280, 1366 | Landscape | Chrome, Edge, Firefox |
| Desktop | 1440, 1920 | Landscape | Chrome, Edge, Firefox, Safari macOS |

Minimum target sentuh 44px; keyboard/focus/aria; kontras; zoom teks 200%; light/dark;
EN default dan toggle ID; no horizontal overflow. Grid dipaginasi/virtualisasi,
adaptive subscriptions, kontrol seluler dalam bottom sheet. Rotasi tidak memulai
room/capture kedua. Layout ukuran diuji otomatis; media nyata pada perangkat fisik
harus dicatat terpisah. Jangan klaim semua perangkat PASS dari emulasi viewport.

## Dukungan bertingkat

Core join/pengawasan/presensi prioritas. Studio efek, pilihan speaker, screen capture,
local recorder dan storage memakai capability detection, bukan nama browser saja.
Tampilkan fallback tanpa merusak room. Di iOS/mobile, jelaskan bila screen sharing/
rekaman komposisi tidak didukung; sediakan desktop/OBS untuk operator. Jangan
menawarkan auto-restart kamera di background yang tidak dapat dijamin browser.
