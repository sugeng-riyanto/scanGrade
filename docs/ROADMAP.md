# Product Roadmap

## Current Version: 1.0.0 (June 2026)

### ✅ Completed Features
- Authentication (admin, teacher, student roles)
- Exam builder (MCQ, essay text, essay canvas)
- PDF upload & page rendering
- Student exam interface with timer
- Drawing tools (pen, ruler, protractor, triangle, compass)
- Scientific calculator
- Anti-cheat system (tab switch, fullscreen, clipboard)
- Teacher grading (manual + batch)
- AI essay grading (Gemini, OpenAI, DeepSeek, Groq)
- Results & analytics
- Export XLSX/PDF
- Multi-school isolation (NPSN-based)
- Subscription & payment (Midtrans)
- Activation codes
- Invoice generation
- RLS security hardening
- Error handling & Sentry monitoring
- Structured logging
- Rate limiting
- Bulk CSV student import
- Pricing & landing pages
- Deployment scripts (systemd + deploy.sh)

### 🔜 Planned (Q3-Q4 2026)

| Feature | Target | Status |
|---------|--------|--------|
| Mobile app (Android/iOS) | Q3 2026 | Research |
| Real-time proctoring (webcam) | Q3 2026 | Research |
| Advanced analytics dashboard | Q3 2026 | Planned |
| Plagiarism detection | Q4 2026 | Planned |
| White-label option | Q4 2026 | Planned |
| Third-party LMS integration (API) | Q4 2026 | Planned |
| Offline mode | Q4 2026 | Research |

### Known Limitations
- No native mobile app (currently web-only)
- No offline exam taking
- AI grading depends on third-party API availability
- PDF upload limited to 50MB
