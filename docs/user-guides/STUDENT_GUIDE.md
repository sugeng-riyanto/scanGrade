# Panduan Siswa — Mengerjakan Ujian

## 1. Akses Ujian

1. Buka link ujian dari guru atau login di `/auth/login-user`
2. Masukkan email dan password (demo: `siswa1_smp@scan-grade.app` / `demo123`)
3. Klik ujian yang tersedia di dashboard

## 2. Sebelum Mulai

Baca **aturan ujian** yang ditampilkan:
- Durasi waktu
- Jumlah soal
- Penalti anti-cheat (pindah tab = peringatan, kedua = -poin)
- Wajib layar penuh (F11)

Klik **Setuju & Mulai**.

## 3. Antarmuka Ujian

| Area | Fungsi |
|------|--------|
| Kiri | Navigasi soal (nomor soal, hijau = terjawab) |
| Tengah | Soal dan pilihan jawaban |
| Atas | Timer, tombol kumpulkan, status sinkron |
| Kanan (hamburger) | Alat bantu & pengaturan |

## 4. Menjawab Soal

**MCQ**: Klik salah satu opsi A/B/C/D/E.

**Esai Teks**: Ketik jawaban di area teks (otomatis tersimpan).

**Esai Canvas**: 
1. Klik **Canvas** untuk membuka alat gambar
2. Pilih pena / penggaris / busur / jangka
3. Gambar/tulis langsung di atas PDF soal
4. Klik **Simpan** untuk menyimpan canvas

## 5. Alat Bantu

- **Kalkulator Ilmiah**: trigonometri, logaritma, memory
- **Penggaris 30cm**: geser & putar
- **Busur 180°**: ukur sudut
- **Segitiga Siku**: set square
- **Jangka**: buat lingkaran

## 6. Anti-Cheat

Sistem memonitor:
- Pindah tab browser → peringatan (1.5 detik)
- Pelanggaran 1: peringatan
- Pelanggaran 2: penalti -N poin
- Pelanggaran 3: penalti -2N poin
- Pelanggaran 4+: penalti -3N poin
- Maksimal pelanggaran → ujian otomatis dikumpulkan

**Jangan** pindah tab atau buka aplikasi lain selama ujian!

## 7. Kumpulkan

1. Klik **Kumpulkan** (tombol merah di atas)
2. Konfirmasi "Yakin ingin mengumpulkan?"
3. Jawaban terkirim → otomatis redirect ke halaman hasil

## 8. Lihat Hasil

Setelah guru mempublikasikan nilai, kamu bisa lihat:
- Skor MCQ
- Skor final (setelah penalti)
- Jawaban benar/salah per soal
- Feedback dari guru atau AI
